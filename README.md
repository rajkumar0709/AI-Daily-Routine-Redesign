# AI-Powered Daily Routine Redesign

## Project Overview
AI-Powered Daily Routine Redesign is a Python-based web application that helps students organize their daily activities, including college, self-study, exercise, and sleep.

## Objectives
- Improve daily time management.
- Create a personalized daily timetable.
- Encourage healthy study and sleep habits.
- Provide smart productivity recommendations.

## Technologies Used
- Python
- Streamlit
- Pandas

## Features
- User input for daily schedules and goals.
- Automatic timetable generation.
- AM/PM time display in the generated timetable.
- Study, exercise, and sleep recommendations.
- Downloadable timetable in CSV format.

## How to Run

1. Install Python.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

4. Open the local URL shown in the terminal.

## Conclusion
This project demonstrates an interactive productivity-planning application that helps students manage their daily routines effectively.
